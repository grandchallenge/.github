# GCT → GCL Mandate Template

**Mandate ID:**  
**GCT sponsoring office(s):**  
**Enterprise disposition before mandate:**  
**Publicity class:** `PUBLIC_SAFE` / `INTERNAL` / `CONFIDENTIAL_REFERENCE_ONLY`  

## Enterprise question

What decision-relevant question is GCT asking?

## Strategic rationale

Why would a credible answer matter to GCT?

## Requested GCL outcome

Define the artifact/evidence/capability return, not the desired conclusion.

## Decision horizon

What future GCT decision should this evidence inform?

## Resource envelope

`UNALLOCATED` or the already-authorized bounded envelope. A mandate does not create new spending authority.

## Non-goals

List what the mandate does not authorize.

## Required evidence class

Examples: reproducible fixture, multi-seed experiment, exact finite verification, independent review, certified result, benchmarked prototype, architecture feasibility packet.

## Acceptable failure outcome

State what negative or null result would still close the question usefully.

## Constraints

Legal, data, licensing, privacy, security, safety, compute, portability, deadline, external dependency.

## Governance route

Identify applicable GCL programme, INTELLECT work-package route, MATHCERT route, AETHER boundary, or other current authority. Do not invent a new route if an admitted one exists.

## Return packet

GCL should return:

- exact artifact/revision identities;
- evidence and replay path;
- claim status/boundary;
- uncertainty/failure modes;
- cost/compute observations;
- reusable capabilities;
- recommended technical next step.

## Post-return GCT dispositions

`INCUBATING` / `ACTIVE` / `ACCELERATE` / `HOLD` / `PRODUCTIZE` / `PARTNER` / `SPIN_OUT_CANDIDATE` / `NARROW` / `RETIRE`.

## Reserved decisions anticipated

List any expected Founder/CEO or separate Human Steward decision. If none, state `NONE_CURRENTLY_IDENTIFIED`.
