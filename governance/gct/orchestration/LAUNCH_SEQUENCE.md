## Stage 3 — Establish Founder attention economy

CONDUCTOR audits current processes for unnecessary Jamie Steeg gates.

Classify each human touchpoint:

- truly reserved;
- governance-required in Human Steward capacity;
- strategically useful but delegable;
- purely clerical and removable.

Convert recurring clerical approvals into standing delegation plus machine-checkable boundaries where safe.

Exit: routine authorized work can close without Founder intervention; reserved powers remain fail-closed.

## Stage 4 — Establish mandate/return loop

Select three current high-value enterprise questions and issue bounded GCT→GCL mandates.

A suitable first portfolio should include:

1. one foundational infrastructure/cognitive-coordination question;
2. one high-option-value frontier research question;
3. one capability with plausible near-term product/commercial translation.

Each mandate defines decision-relevant evidence and an acceptable negative outcome.

Exit: GCT can commission governed GCL work and receive evidence without corrupting claim authority.

## Stage 5 — Product and commercialization sieve

CPO + CCP + CTO + CTA examine evidenced capabilities using four gates:

1. **Capability:** does it reliably do something valuable?
2. **User:** who has a real costly problem or newly possible action?
3. **Delivery:** can GCT deliver/operate it responsibly?
4. **Economics:** is there a plausible sustainable value exchange?

Only capabilities passing the appropriate stage advance. Research prestige is not a substitute for a product path.

Exit: `PRODUCT_VENTURE_PORTFOLIO` and `OPPORTUNITY_PIPELINE` contain evidence-linked options rather than generic business-development ideas.

Exit: no material corporate obligation is known only to chat history or a model.

Do not displace the strong existing GCL laboratory front page until the information architecture is deliberately chosen.

## Stage 8 — Compounding institution

Each quarterly cycle asks:

- Which research line became a reusable capability?
- Which capability became a product/platform?
- Which product/platform deserves separate venture/subsidiary form?
- Which shared infrastructure should become a GCT asset?
- Which programmes should be retired?
- Which Founder decisions should become safer standing delegation?

The intended flywheel is:

```text
Grand question
→ governed research
→ inspectable knowledge
→ reusable capability
→ product/platform/venture
→ resources and external contact
→ stronger capacity for the next grand question
```

That flywheel is the operational expression of GCT's grand ambition.
